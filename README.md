# AMR analysis

The complete analysis code is contained in [`amr_v3.0.Rmd`](amr_v3.0.Rmd).
The corresponding rendered output, including the results and figures, can be
viewed in [`amr_v3.0.html`](amr_v3.0.html).

To run the analysis, open the R Markdown file in RStudio and knit it to HTML.
The only necessary code change is to remove the `#` comment markers from the
sections that are currently commented out, as these sections prevent the
models from running in the current version.
