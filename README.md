All of the analyses in the manuscript can be reproduced by running amr_v1.9.Rmd script in the programming language R (Version 4.2.3). This script loads the data, runs models and produces the manuscript figures

All other files in the script represent the underlying data:

- DATA_AMR_jul2023_ISO3_LAT_LON 2.csv contains the baterial isolate data
- species_level_tree (2).newick is the bacterial phylogeny
- data_health_wb.csv contains information on health expenditure and disease rates. Sourced from the world bank
- data_governance_wb.csv describes governance scores for each country per year. Sourced from the world bank
- data_anti.csv contains information on human antimicrobial use
- data_anti2.csv contains information on livestock antimicrobial use
- data_enviro_wb.csv contains information on enivronemtal features e.g. air pollution. Sourced from the world bank
- data_population_un.csv describes population information e.g. life expectancy and national population density. Sourced from the UN national statisitcs.
- struc.csv contains data from strucutured resistance monitoring schemes
